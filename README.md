# Quản lý bài viết bản tin — Trường Chính trị tỉnh Tây Ninh

Bản giới thiệu công khai, mở trực tiếp, không cần tài khoản.

Các màn hình: Tổng quan, Bài viết, Phản biện, Số bản tin và Báo cáo. Có tìm kiếm, lọc trạng thái, hồ sơ bài viết, lịch sử xử lý và sơ đồ quy trình.

Ứng dụng sử dụng dữ liệu mẫu để xem giao diện và quy trình; chưa lưu, nộp hay duyệt bài viết thật.

Triển khai bằng GitHub Pages từ nhánh `main`, thư mục gốc. Trang chạy độc lập với Codespaces.
